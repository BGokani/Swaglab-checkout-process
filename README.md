# 🛒 SwagLab Checkout Process Automation

This repository contains an end-to-end automation script for the [SauceDemo](https://www.saucedemo.com/) website.  
It covers the complete user flow from login to logout using Selenium with Python and follows the **Page Object Model (POM)** structure.

---

## Features

- Login using credentials from config
- Parameterized selection of products
- Add items to cart
- Cart verification with name & price
- Checkout with random user details
- Price total and quantity validation
- Order confirmation and logout
- Failure screenshots on error
- Code organized using POM
- Data-driven and configurable
